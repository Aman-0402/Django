# Django & Flask Ebook

Interactive web-based ebook covering Django, Flask, and bonus content.

## Live Site

**[https://aman-0402.github.io/Django/](https://aman-0402.github.io/Django/)**

## Contents

| Section | Description |
|---------|-------------|
| **Django** | Full Django tutorial — setup, MVT architecture, models, views, templates, admin |
| **Flask** | Flask fundamentals — routing, templates, request/response cycle |
| **Venom** | Bonus section |

## Tech

- Pure HTML, CSS, JavaScript (no framework)
- Animated floating icons (Django, Flask, FastAPI, Python, JS, MySQL, VS Code, HTML5)
- Card-based navigation UI

## Project Structure

```
Django/
├── index.html          # Landing page with card navigation
├── styles.css          # Global styles + floating icon animations
├── scripts.js          # JS
├── assets/             # Logos and images
├── contents/
│   ├── Django/         # Django ebook pages
│   ├── Flask/          # Flask ebook pages
│   └── Pikachu/        # Venom bonus section
└── extra/
```

## Local Dev

Open `index.html` directly in browser — no build step needed.
