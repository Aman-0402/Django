Course Learning Portal

Build a professional, scalable course platform using Flask, databases, and clean architecture.

🎯 What We Are Building

  • Users can see a list of courses
  • Users can open course detail pages
  • Admin can add and edit courses
  • Backend uses Flask with database
  • Clean and scalable project structure

🧱 Tech Stack (Intermediate Level)

  • Flask
  • Flask Blueprints
  • Flask-SQLAlchemy
  • Jinja2 Templates
  • SQLite (for now)
  • Basic Admin Logic (no Flask-Admin yet)

✅ STEP 1: Project Initialization & Environment Setup

By the end of this step, you will have:

  • A clean project folder
  • A virtual environment
  • Flask installed
  • A running Flask application

📁 Step 1.1: Create Project Folder

Choose any workspace (Desktop or E:\FlaskProjects)

mkdir course_learning_portal
  cd course_learning_portal

Why this name?

  • Professional
  • Resume-friendly
  • Scalable for upgrades

🐍 Step 1.2: Create Virtual Environment

python -m venv venv

Activate it (Windows):

venv\Scripts\activate

Activate it (Linux / Mac):

source venv/bin/activate

After activation, you should see (venv) in your terminal.

📦 Step 1.3: Install Flask

pip install flask

Verify installation:

pip show flask

📄 Step 1.4: Create Entry File

Create a file named app.py:

from flask import Flask
  
  app = Flask(__name__)
  
  @app.route("/")
  def home():
      return "Course Learning Portal - Flask App Running"
  
  if __name__ == "__main__":
      app.run(debug=True)

▶ Step 1.5: Run the App

python app.py

Open in browser:

http://127.0.0.1:5000/

✅ If you see Course Learning Portal - Flask App Running, your setup is successful.
