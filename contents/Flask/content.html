Flask Framework

Lightweight Python Web Framework

What is Flask?

Flask is a lightweight and flexible Python web framework used to build web applications quickly and efficiently.

It is called a micro-framework because it does not include built-in ORM, authentication, or admin panels by default.

Why Use Flask?

  • Minimal & lightweight
  • Easy to learn for beginners
  • High flexibility & customization
  • Perfect for APIs & small projects

Where Flask is Used?

  • REST APIs
  • Microservices
  • Startup MVPs
  • Backend for mobile apps

Flask vs Django

Flask Django
Micro-framework Full-stack framework
More control More features built-in
