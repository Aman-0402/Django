Templates & Static Files

Using Jinja templates, CSS, JavaScript, and images in Flask

📘 Topic 1: Jinja2 Template Engine (Basics)

Jinja2 is the template engine used by Flask to create dynamic HTML pages by combining HTML with Python data.

1️⃣ What is a Template Engine?

A template engine allows you to:

  • Write normal HTML
  • Insert Python data into HTML
  • Generate dynamic web pages

👉 Flask uses Jinja2 as its default template engine.

2️⃣ Why Jinja2 is Needed?

Without Jinja2 ❌

  • Only static HTML pages are possible

With Jinja2 ✅

  • Display dynamic data
  • Loop through data
  • Apply conditions

Example Output:


    Hello Aman
    Hello Rahul
    Hello Priya

(All generated from a single HTML file)

3️⃣ Templates Folder Rule

Flask automatically looks for HTML files inside the templates folder.

Example Structure:


    flask_app/
    │
    ├── app.py
    └── templates/
        └── index.html

4️⃣ Rendering a Template in Flask

app.py


    from flask import Flask, render_template
    
    app = Flask(__name__)
    
    @app.route("/")
    def home():
        return render_template("index.html")

5️⃣ Basic HTML Template

templates/index.html


    <!DOCTYPE html>
    <html>
    <head>
      <title>Flask Template</title>
    </head>
    <body>
      <h1>Welcome to Flask</h1>
    </body>
    </html>

6️⃣ Passing Data from Flask to Template

app.py


    @app.route("/user")
    def user():
        name = "Aman"
        return render_template("user.html", username=name)

templates/user.html


    <h1>Hello {{ username }}</h1>

👉 {{ }} is used to print dynamic data in HTML.

7️⃣ How Jinja2 Works (Flow)


    Browser → Request
    Flask   → render_template()
    Jinja2  → injects data
    HTML    → returned to browser

8️⃣ Jinja2 Syntax Basics

Syntax Purpose
{{ }} Print variable
{% %} Logic (if, for)
{# #} Comment

9️⃣ Jinja2 Comment Example


    {# This is a Jinja comment #}

(This comment is not visible in the browser)

📘 Topic 2: Template Variables & Expressions

This topic explains how data flows from Flask (Python) to HTML templates using Jinja2 variables, expressions, and filters.

1️⃣ What are Template Variables?

Template variables are Python values sent from Flask and used inside HTML templates.

Example (Python):


    name = "Aman"

Used in template as:


    {{ name }}

2️⃣ Passing Multiple Variables

app.py


    @app.route("/profile")
    def profile():
        return render_template(
            "profile.html",
            name="Aman",
            age=22,
            course="Flask"
        )

profile.html


    <h2>Name: {{ name }}</h2>
    <p>Age: {{ age }}</p>
    <p>Course: {{ course }}</p>

3️⃣ Using Expressions in Templates

Jinja2 expressions allow simple calculations and operations directly inside HTML.

Example:


    <p>Next Year Age: {{ age + 1 }}</p>

4️⃣ Using Python Data Types (List)

app.py


    @app.route("/courses")
    def courses():
        course_list = ["Flask", "Django", "FastAPI"]
        return render_template("courses.html", courses=course_list)

courses.html


    <ul>
      {% for course in courses %}
        <li>{{ course }}</li>
      {% endfor %}
    </ul>

5️⃣ Using Dictionary in Template

app.py


    @app.route("/student")
    def student():
        data = {"name": "Aman", "course": "Flask"}
        return render_template("student.html", student=data)

student.html


    <p>Name: {{ student.name }}</p>
    <p>Course: {{ student.course }}</p>

6️⃣ Jinja2 Filters (Simple)

Filters are used to modify how data is displayed in templates. 


    <p>{{ name | upper }}</p>
    <p>{{ name | lower }}</p>
    <p>{{ name | length }}</p>

7️⃣ Commonly Used Filters

Filter Output
upperCAPITAL
lowersmall
lengthcount
titleTitle Case

📘 Topic 3: Control Statements (if, for loop)

Control statements allow templates to make decisions and loop through data. They help in building dynamic and intelligent HTML pages.

1️⃣ What are Control Statements?

Control statements allow:

  • Applying conditions using if
  • Looping through data using for
  • Dynamic rendering of HTML content

👉 Control statements are written using {% %}.

2️⃣ if Statement in Jinja2

Template Example:


    {% if is_logged_in %}
      <p>Welcome User</p>
    {% else %}
      <p>Please Login</p>
    {% endif %}

Flask Side (app.py):


    @app.route("/login-status")
    def login_status():
        return render_template("status.html", is_logged_in=True)

3️⃣ Comparison Operators Supported

Example:


    {% if age >= 18 %}
      <p>Adult</p>
    {% endif %}

Supported operators:

  • ==
  • !=
  • >
  • <
  • >=
  • <=

4️⃣ for Loop in Jinja2

Template Example:


    <ul>
    {% for item in items %}
      <li>{{ item }}</li>
    {% endfor %}
    </ul>

Flask Side:


    @app.route("/items")
    def items():
        data = ["Python", "Flask", "Django"]
        return render_template("items.html", items=data)

5️⃣ Loop with Dictionary


    {% for key, value in student.items() %}
      <p>{{ key }} : {{ value }}</p>
    {% endfor %}

6️⃣ Loop Special Variables


    {% for course in courses %}
      {{ loop.index }} - {{ course }} <br>
    {% endfor %}
Variable Meaning
loop.indexStarts from 1
loop.index0Starts from 0
loop.firstTrue / False
loop.lastTrue / False

7️⃣ Nested if inside loop


    {% for age in ages %}
      {% if age >= 18 %}
        <p>{{ age }} Adult</p>
      {% endif %}
    {% endfor %}

📘 Topic 4: Template Inheritance (base.html)

Template inheritance helps you avoid repeating the same HTML code across multiple pages by using a common base layout.

1️⃣ Problem Without Template Inheritance ❌

If you do not use template inheritance:

  • The same navbar must be copied into every page
  • The same footer is repeated everywhere
  • Updating the design becomes difficult

2️⃣ Solution: Template Inheritance ✅

The solution is to create one main layout and reuse it across all pages.

  • base.html → Common layout
  • home.html → Page-specific content
  • about.html → Page-specific content

3️⃣ What is base.html?

base.html is the main layout file that usually contains:

  • HTML structure
  • Header
  • Navbar
  • Footer
  • Content blocks

4️⃣ Create base.html

templates/base.html


    <!DOCTYPE html>
    <html>
    <head>
      <title>{% block title %}Flask App{% endblock %}</title>
    </head>
    <body>
    
      <header>
        <h1>My Flask Website</h1>
      </header>
    
      <main>
        {% block content %}
        {% endblock %}
      </main>
    
      <footer>
        <p>© 2025 Flask App</p>
      </footer>
    
    </body>
    </html>

5️⃣ Create Child Template

templates/home.html


    {% extends "base.html" %}
    
    {% block title %}Home{% endblock %}
    
    {% block content %}
      <h2>Welcome Home</h2>
      <p>This is home page content.</p>
    {% endblock %}

6️⃣ Render Child Template in Flask

app.py


    @app.route("/")
    def home():
        return render_template("home.html")

7️⃣ How Inheritance Works (Simple Flow)


    base.html loads
       ↓
    child.html extends base
       ↓
    block content replaced
       ↓
    final HTML sent to browser

8️⃣ Rules You MUST Remember 🔥

  • {% extends %} must be the first line in the child template
  • {% block %} names must match exactly
  • You can create multiple blocks in one base template

9️⃣ Common Blocks Used


    {% block title %}{% endblock %}
    {% block content %}{% endblock %}
    {% block scripts %}{% endblock %}

📘 Topic 5: Include & Macros

Include and Macros help you reuse template parts and keep your HTML clean, readable, and maintainable in large Flask applications.

1️⃣ Why Include & Macros?

Problems without them ❌

  • Repeated navbar and footer code
  • Very large and messy HTML files

Solution ✅

  • include → Reuse template files
  • macros → Reuse template logic (like functions)

2️⃣ {% include %} – Reuse HTML Files

Use include when you want to reuse:

  • Navbar
  • Footer
  • Sidebar

3️⃣ Create Navbar Template

templates/navbar.html


    <nav>
      <a href="/">Home</a> |
      <a href="/about">About</a> |
      <a href="/contact">Contact</a>
    </nav>

4️⃣ Include Navbar in base.html

templates/base.html


    <body>
    
      {% include "navbar.html" %}
    
      <main>
        {% block content %}{% endblock %}
      </main>
    
    </body>

👉 The navbar will now appear on every page.

5️⃣ Include Footer Example

templates/footer.html


    <footer>
      <p>© 2025 Flask App</p>
    </footer>

Include it using:


    {% include "footer.html" %}

6️⃣ What are Macros? (Template Functions)

Macros are like functions inside templates and are used to reuse UI logic.

Used for:

  • Buttons
  • Cards
  • Repeated UI components

7️⃣ Create a Macro File

templates/macros.html


    {% macro button(text) %}
      <button>{{ text }}</button>
    {% endmacro %}

8️⃣ Use Macro in Another Template


    {% from "macros.html" import button %}
    
    {{ button("Login") }}
    {{ button("Register") }}

9️⃣ Macro with Parameters


    {% macro card(title, desc) %}
      <div class="card">
        <h3>{{ title }}</h3>
        <p>{{ desc }}</p>
      </div>
    {% endmacro %}

Usage:


    {{ card("Flask", "Python Web Framework") }}

🔥 Include vs Macros (Quick Comparison)

Include Macro
Reuse HTML fileReuse logic
Static contentDynamic content
Navbar / FooterButtons / Cards

📘 Topic 6: Static Files (CSS, JS, Images)

Static files are resources that do not change dynamically, such as CSS, JavaScript, and images. Flask serves these files from a dedicated folder.

1️⃣ What are Static Files?

Static files include:

  • CSS → Styling and layout
  • JavaScript → Interactivity and behavior
  • Images → Logos, banners, icons

👉 Flask serves static files from the static folder.

2️⃣ Static Folder Rule (IMPORTANT)

Flask automatically looks for static files inside the static/ directory.

Recommended Structure:


    flask_app/
    │
    ├── app.py
    ├── static/
    │   ├── css/
    │   │   └── style.css
    │   ├── js/
    │   │   └── script.js
    │   └── images/
    │       └── logo.png
    └── templates/
        └── base.html

3️⃣ Linking CSS File (Correct Way)

base.html


    <link rel="stylesheet"
          href="{{ url_for('static', filename='css/style.css') }}">

❌ Wrong Way:


    <link rel="stylesheet" href="/static/css/style.css">

👉 Always use url_for() because it is safe and professional.

4️⃣ Sample CSS File

static/css/style.css


    body {
      font-family: Arial, sans-serif;
      background: #f5f5f5;
    }

5️⃣ Linking JavaScript File

base.html


    <script src="{{ url_for('static', filename='js/script.js') }}"></script>

static/js/script.js


    console.log("Flask JS Loaded");

6️⃣ Using Images in Template


    <img src="{{ url_for('static', filename='images/logo.png') }}"
         alt="Logo">

7️⃣ Why url_for() is IMPORTANT 🔥

  • ✔ Works in all environments (local, server, production)
  • ✔ Prevents broken links
  • ✔ Recommended Flask best practice

8️⃣ Static Files with Template Inheritance

Static files are usually linked inside base.html. 


    <head>
      <link rel="stylesheet"
            href="{{ url_for('static', filename='css/style.css') }}">
    </head>
    
    <body>
      {% block content %}{% endblock %}
      <script src="{{ url_for('static', filename='js/script.js') }}"></script>
    </body>

📘 Topic 7: URL Generation (url_for)

url_for() is used to generate safe and dynamic URLs in Flask. It helps avoid broken links and makes applications easier to maintain.

1️⃣ Problem with Hardcoded URLs ❌


    <a href="/about">About</a>

Why this is bad?

  • Breaks if the route path changes
  • May break during deployment
  • Hard to maintain in large projects

2️⃣ Solution: url_for() ✅


    <a href="{{ url_for('about') }}">About</a>

👉 Flask automatically generates the correct URL.

3️⃣ How url_for() Works

Flask Route:


    @app.route("/about")
    def about():
        return render_template("about.html")

Template:


    <a href="{{ url_for('about') }}">About</a>
  • about → Function name
  • Flask maps it automatically to /about

4️⃣ url_for() with Parameters

Route with parameter:


    @app.route("/user/<name>")
    def user(name):
        return render_template("user.html", name=name)

Template:


    <a href="{{ url_for('user', name='Aman') }}">Profile</a>

Generated URL:


    /user/Aman

5️⃣ url_for() for Static Files (Revision)


    <link rel="stylesheet"
          href="{{ url_for('static', filename='css/style.css') }}">

6️⃣ url_for() Inside Python Code


    from flask import redirect, url_for
    
    @app.route("/go-home")
    def go_home():
        return redirect(url_for("home"))

7️⃣ Benefits of Using url_for()

  • No broken links
  • Clean and maintainable navigation
  • Safe for deployment
  • Professional Flask code

8️⃣ Common Mistakes ❌

Mistake Fix
Using route URL directly Use function name in url_for()
Hardcoding links Use url_for()
Wrong parameter name Match route parameter exactly
