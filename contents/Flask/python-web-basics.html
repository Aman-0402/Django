Python & Web Basics

Before learning Flask, it is essential to refresh the core Python concepts that are commonly used in web development.

📘 Topic 1: Python Refresher for Web Development

Flask is written in Python. That means Python handles all backend logic such as requests, responses, databases, and APIs.

1️⃣ Why Python for Web Development?

Python is widely used in web development because it is:

  • Easy to read and write
  • Powerful for backend logic
  • Supported by frameworks like Flask and Django
  • Capable of handling databases, APIs, authentication, and more

👉 Important: In Flask, Python handles backend logic, not design.

2️⃣ Python Concepts You MUST Know for Flask

You do not need to learn complete Python. Only the following concepts are essential for Flask development.

🔹 2.1 Variables & Data Types


      name = "Aman"
      age = 22
      price = 99.50
      is_active = True

Notes:

  • Variables store user data, form data, and database data
  • Python automatically detects the data type

🔹 2.2 Strings (Very Important)


      username = "admin"
      message = f"Welcome {username}"
      print(message)

Used in Flask for:

  • Messages
  • HTML responses
  • JSON responses

🔹 2.3 Lists & Dictionaries (MOST USED)

List Example:


      courses = ["Flask", "Django", "FastAPI"]

Dictionary Example:


      student = {
          "name": "Aman",
          "course": "Flask",
          "active": True
      }

Flask Usage:

  • Lists → Display multiple items in HTML
  • Dictionaries → Pass structured data to templates

🔹 2.4 Conditional Statements (if–else)


      age = 18
      
      if age >= 18:
          print("Allowed")
      else:
          print("Not Allowed")

Flask Usage:

  • Login checks
  • User role validation
  • Form validation

🔹 2.5 Loops


      courses = ["Flask", "Django", "FastAPI"]
      
      for course in courses:
          print(course)

Flask Usage:

  • Display database records
  • Create HTML tables and lists

🔹 2.6 Functions (VERY IMPORTANT)


      def greet(name):
          return f"Hello {name}"
      
      print(greet("Aman"))

Flask Reality:

👉 Every Flask route is a Python function.

🔹 2.7 Modules & Imports


      import math
      print(math.sqrt(16))

Custom Module Example:


      # utils.py
      def add(a, b):
          return a + b
        

      # main.py
      from utils import add
      print(add(5, 3))

Flask Usage:

  • Code reuse
  • Clean project structure

3️⃣ Python Virtual Environment (VERY IMPORTANT)

A virtual environment isolates project dependencies so that each project remains clean and conflict-free.

Without virtual environment ❌

  • Version conflicts
  • Unstable projects

With virtual environment ✅

  • Safe dependency management
  • Clean Flask projects

Create Virtual Environment


      python -m venv venv

Activate (Windows)


      venv\Scripts\activate

Activate (Linux / Mac)


      source venv/bin/activate

After activation, you will see (venv) in the terminal.

4️⃣ pip (Python Package Manager)


      pip install flask
      pip list
      pip freeze > requirements.txt

📝 Short Notes (For Your Notebook)

  • Python is the backend language for Flask
  • Functions act as Flask routes
  • Lists and dictionaries handle data
  • Virtual environments isolate dependencies
  • pip installs Flask and other libraries
