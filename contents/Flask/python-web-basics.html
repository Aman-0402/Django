Python & Web Basics

Before learning Flask, it is essential to refresh the core Python concepts that are commonly used in web development.

📘 Topic 1: Python Refresher for Web Development

Flask is written in Python. That means Python handles all backend logic such as requests, responses, databases, and APIs.

1️⃣ Why Python for Web Development?

Python is widely used in web development because it is:

  • Easy to read and write
  • Powerful for backend logic
  • Supported by frameworks like Flask and Django
  • Capable of handling databases, APIs, authentication, and more

👉 Important: In Flask, Python handles backend logic, not design.

2️⃣ Python Concepts You MUST Know for Flask

You do not need to learn complete Python. Only the following concepts are essential for Flask development.

🔹 2.1 Variables & Data Types

Topic 2: How the Web Works (HTTP, Request & Response)

Before learning Flask, it is important to understand what actually happens behind the scenes when you open a website.

1️⃣ What is the Web?

The web works on the Client–Server model.

Simple Meaning:

  • Client → Browser (Chrome, Edge, Mobile)
  • Server → Flask App (Python)
  • Internet → Communication medium

2️⃣ Client–Server Architecture

Real-Life Example 🍔

  • You → Client (orders food)
  • Restaurant → Server (prepares food)
  • Waiter → Internet (delivers food)

Same in Web:


      Browser  →  Request  →  Server (Flask)
      Browser  ←  Response ←  Server

3️⃣ What is HTTP?

HTTP stands for HyperText Transfer Protocol. It is a set of rules that allows browsers and servers to communicate.

4️⃣ HTTP Request

When you open a website, the browser sends an HTTP request to the server.

A request contains:

  • URL
  • Method (GET / POST)
  • Headers
  • Data (optional)

Example:


      GET /home HTTP/1.1

5️⃣ HTTP Response

The server processes the request and sends an HTTP response back to the browser.

A response contains:

  • Status Code (200, 404, etc.)
  • Headers
  • Body (HTML / JSON / Text)

Example:


      200 OK
      <h1>Welcome</h1>

6️⃣ HTTP Methods (IMPORTANT)

🔹 GET

  • Used to fetch data
  • Examples: Open website, search page

🔹 POST

  • Used to send data to the server
  • Examples: Login form, registration form

7️⃣ Common HTTP Status Codes

Code Meaning
200Success
201Created
400Bad Request
401Unauthorized
403Forbidden
404Page Not Found
500Server Error

8️⃣ Request–Response Cycle (Flask Flow)


      Browser
         ↓
      HTTP Request
         ↓
      Flask Route (Python Function)
         ↓
      Processing Logic
         ↓
      HTTP Response
         ↓
      Browser shows result

👉 Flask receives the request, processes the logic, and returns a response.

9️⃣ Simple Flask Preview (Concept Only)


      from flask import Flask
      
      app = Flask(__name__)
      
      @app.route("/")
      def home():
          return "Hello Flask"

What happens here?

  • Browser requests /
  • Flask calls home()
  • Flask returns "Hello Flask"

📝 Short Notes (Copy This)

  • The web uses the Client–Server model
  • Browser sends an HTTP request
  • Server returns an HTTP response
  • Flask handles requests using routes
  • GET is used to fetch data
  • POST is used to send data

Topic 3: Client–Server Architecture (Frontend vs Backend)

This topic removes all confusion about where Flask works and clearly separates frontend and backend responsibilities.

1️⃣ What is Client?

The Client is also called the Frontend. It is the part of the application that users directly interact with.

Examples:

  • Web Browser (Chrome, Edge)
  • Mobile Applications
  • API tools like Postman

Client Responsibilities:

  • Display UI using HTML and CSS
  • Collect user input
  • Send requests to the server

2️⃣ What is Server?

The Server is also known as the Backend. It handles logic, security, and data processing.

Examples:

  • Flask Application
  • Django Application
  • Node.js Application

Server Responsibilities:

  • Process business logic
  • Handle database operations
  • Authenticate users
  • Send responses back to the client

3️⃣ Frontend vs Backend

Frontend Backend
HTMLPython
CSSFlask
JavaScriptDatabase
Runs in browserRuns on server

👉 Important: Flask is a Backend Framework.

4️⃣ Where Flask Stands?


      Browser (HTML / CSS / JS)
              ↓
           Flask (Python)
              ↓
           Database

Flask Responsibilities:

  • Receive HTTP requests
  • Apply application logic
  • Communicate with the database
  • Return HTTP responses

5️⃣ Example: Login Page Flow

  1. User enters email and password
  2. Browser sends a POST request
  3. Flask verifies credentials
  4. Flask returns success or error

6️⃣ Simple Flask Backend Example


      from flask import Flask
      
      app = Flask(__name__)
      
      @app.route("/login")
      def login():
          return "Login Page"

👉 The browser displays the response, but Flask handled the backend logic.

7️⃣ Full Web App Flow (Real World)


      User clicks button
           ↓
      Browser sends request
           ↓
      Flask route executes
           ↓
      Business logic
           ↓
      Database query
           ↓
      Flask returns response
           ↓
      Browser updates UI

8️⃣ Backend Types You’ll Build with Flask

  • Websites (HTML-based responses)
  • REST APIs (JSON responses)
  • Admin dashboards
  • Microservices

Topic 4: REST Basics (API Fundamentals)

Almost all modern Flask applications use REST APIs. Understanding REST is essential before building real-world Flask projects.

1️⃣ What is an API?

API stands for Application Programming Interface. It allows two software programs to communicate with each other.

Simple Meaning:

  • Frontend ↔ Backend
  • Mobile App ↔ Flask Server
  • React ↔ Flask API

2️⃣ What is REST?

REST stands for Representational State Transfer. It is a set of guidelines used to design clean and structured APIs.

3️⃣ Why REST is Important?

Without REST ❌

  • Messy URLs
  • Hard-to-maintain logic

With REST ✅

  • Clean URL structure
  • Easy to maintain
  • Scalable applications

4️⃣ REST Uses HTTP Methods

Method Action
GETRead data
POSTCreate data
PUTUpdate data
DELETEDelete data

👉 These methods directly map to CRUD operations.

5️⃣ REST URL Examples


      GET    /users       → Get all users
      GET    /users/1     → Get a single user
      POST   /users       → Create a new user
      PUT    /users/1     → Update user data
      DELETE /users/1     → Delete a user

6️⃣ REST Response Format (JSON)

Flask APIs typically return data in JSON format. 


      {
        "id": 1,
        "name": "Aman",
        "course": "Flask"
      }

7️⃣ Simple Flask REST Example (Preview)


      from flask import Flask, jsonify
      
      app = Flask(__name__)
      
      @app.route("/api")
      def api():
          return jsonify({
              "message": "Hello REST API"
          })

Browser Output:


      {
        "message": "Hello REST API"
      }

8️⃣ REST API vs Website

Website REST API
Returns HTMLReturns JSON
For usersFor applications
Browser-basedBrowser, Mobile, React

9️⃣ Real-Life Example 📱

Instagram Flow:

  • App sends request to API
  • API returns JSON data
  • App displays the UI

🔥 The same approach is used when building REST APIs with Flask.

Topic 5: Virtual Environment (venv)

Using a virtual environment is mandatory for every professional Flask project. It keeps your project clean, isolated, and manageable.

1️⃣ What is a Virtual Environment?

A virtual environment is a separate Python workspace created for a single project.

Why is it needed?

Without virtual environment ❌

  • Package version conflicts
  • Global Python installation becomes messy

With virtual environment ✅

  • Project-specific packages
  • Clean and professional setup

2️⃣ Real-Life Analogy 🎒

  • Laptop → System Python
  • Bag → Virtual environment
  • Books inside bag → Flask packages

Each project carries its own bag.

3️⃣ Create Flask Project Folder


      mkdir flask_app
      cd flask_app

4️⃣ Create Virtual Environment


      python -m venv venv

After running the command, the folder structure will look like this:


      flask_app/
      │
      ├── venv/

5️⃣ Activate Virtual Environment

🔹 Windows


      venv\Scripts\activate

🔹 Linux / Mac


      source venv/bin/activate

After activation, you will see (venv) in the terminal.

👉 This confirms that the virtual environment is active.

6️⃣ Install Flask (Inside venv)


      pip install flask

Verify installation:


      pip list

You should see packages like:

  • Flask
  • Werkzeug
  • Jinja2

7️⃣ Freeze Dependencies (IMPORTANT)


      pip freeze > requirements.txt

This creates a file named requirements.txt.

Example content:


      Flask==3.x.x

👉 This file is used when sharing or deploying your Flask project.

8️⃣ Deactivate Virtual Environment


      deactivate

Topic 6: pip & Dependency Management

pip is the official tool used to install Flask and all required Python libraries. Proper dependency management is essential for professional Flask projects.

1️⃣ What is pip?

pip stands for Python Package Installer. It is used to install Python libraries from PyPI (Python Package Index).

2️⃣ Why pip is Important?

  • Flask is installed using pip
  • Databases, authentication, and APIs are installed via pip
  • Required for deployment and production setups

3️⃣ Basic pip Commands (MUST KNOW)

🔹 Check pip version


      pip --version

🔹 Install a package


      pip install flask

🔹 Install a specific version


      pip install flask==3.0.0

🔹 Uninstall a package


      pip uninstall flask

🔹 List installed packages


      pip list

4️⃣ requirements.txt (VERY IMPORTANT)

requirements.txt is a file that contains all the dependencies used in a Flask project.

Example:


      Flask==3.0.0

🔹 Create requirements.txt


      pip freeze > requirements.txt

🔹 Install dependencies from requirements.txt


      pip install -r requirements.txt

Used when:

  • Sharing a project
  • Deploying to production
  • Working in a team

5️⃣ Best Practices (Professional Tips)

✔ Always:

  • Activate virtual environment
  • Install packages inside venv
  • Freeze dependencies regularly

❌ Never:

  • Install Flask globally
  • Skip requirements.txt

6️⃣ Common Beginner Mistakes

Mistake Fix
Flask not found Activate virtual environment
Wrong Flask version Use version pinning
App works only on my PC Use requirements.txt
