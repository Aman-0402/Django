Flask Core (Beginner)

📘 Topic 1: What is Flask & Why Flask

This topic explains what Flask is, why it is used, and where it fits in real-world projects.

1️⃣ What is Flask?

Flask is a lightweight Python web framework used to build:

  • Web applications
  • REST APIs
  • Backend services

Simple Meaning:

Flask helps Python receive requests from clients and send responses back.

2️⃣ Why Flask is Called a Microframework?

Flask is called a microframework because it provides only the core features and leaves the rest to the developer.

  • No built-in database
  • No built-in authentication system
  • No forced project structure

👉 You add only what your project actually needs.

3️⃣ What Flask Gives You by Default

  • URL routing
  • Request handling
  • Response handling
  • Jinja2 templating engine
  • Built-in development server

4️⃣ Flask vs Django (Quick View)

Flask Django
LightweightHeavy
FlexibleOpinionated
Best for APIsBest for large applications
Beginner friendlySteeper learning curve

👉 Conclusion: Flask gives you more control.

5️⃣ When Should You Use Flask?

Use Flask when:

  • You want to build REST APIs
  • You want full control over your application
  • You prefer a simple and flexible structure
  • You are building microservices

6️⃣ Companies Using Flask

  • Netflix
  • Reddit
  • Airbnb
  • Uber

7️⃣ How Flask Works (Flow)


    Browser
       ↓
    Flask Route
       ↓
    Python Logic
       ↓
    Response

8️⃣ Minimal Flask Code (Preview)


    from flask import Flask
    
    app = Flask(__name__)
    
    @app.route("/")
    def home():
        return "Hello Flask"

📘 Topic 2: Installing Flask

In this topic, we will install Flask properly using a virtual environment and pip. This is the correct and professional way to start any Flask project.

1️⃣ Prerequisites

Before installing Flask, make sure the following are ready:

  • Python is installed
  • Virtual environment is created
  • Virtual environment (venv) is activated

Check Python version:


    python --version

2️⃣ Activate Virtual Environment

Navigate to your project folder:


    cd flask_app

🔹 Windows


    venv\Scripts\activate

🔹 Linux / Mac


    source venv/bin/activate

After activation, you should see (venv) in the terminal.

3️⃣ Install Flask Using pip


    pip install flask

4️⃣ Verify Flask Installation

🔹 Method 1: Using pip


    pip list

You should see packages like:

  • Flask
  • Werkzeug
  • Jinja2

🔹 Method 2: Using Python Shell


    python
      

    import flask
    print(flask.__version__)

5️⃣ What Gets Installed with Flask?

Package Purpose
FlaskMain framework
WerkzeugRequest handling & routing
Jinja2Template engine
MarkupSafeHTML safety
ClickCommand-line interface

👉 These packages are Flask’s internal dependencies and are installed automatically.

6️⃣ Save Dependencies (Best Practice)


    pip freeze > requirements.txt

This ensures your project can be easily shared, deployed, or reproduced on another system.

📘 Topic 3: Flask Project Structure

Understanding the project structure early helps you write clean code, avoid confusion, and follow professional development standards.

1️⃣ Why Project Structure Matters?

A good project structure helps you to:

  • Organize your code properly
  • Scale projects easily
  • Debug issues faster
  • Follow professional coding standards

2️⃣ Basic Flask Project Structure (Beginner)


    flask_app/
    │
    ├── venv/
    │
    ├── app.py
    ├── requirements.txt

Explanation:

  • venv/ → Virtual environment
  • app.py → Main Flask application file
  • requirements.txt → List of project dependencies

👉 This structure is perfect for beginners and learning Flask basics.

3️⃣ Slightly Better Structure (Recommended)


    flask_app/
    │
    ├── venv/
    ├── app.py
    ├── templates/
    │   └── index.html
    ├── static/
    │   ├── css/
    │   └── js/
    └── requirements.txt

4️⃣ Folder Purpose (IMPORTANT)

🔹 app.py

  • Entry point of the Flask application
  • Contains routes and backend logic

🔹 templates/

  • Stores HTML files
  • Used by Flask to render dynamic pages
  • Uses the Jinja2 template engine

🔹 static/

  • CSS files
  • JavaScript files
  • Images

👉 Flask automatically recognizes the static folder.

5️⃣ Why Templates & Static Are Separate?

Folder Purpose
templates Dynamic HTML rendered by Flask
static CSS, JavaScript, and images

This separation keeps the project clean, readable, and professional.

6️⃣ Naming Rules (Best Practices)

  • Use lowercase names
  • Use app.py or main.py for the main file
  • Avoid spaces in folder and file names

📘 Topic 4: Creating First Flask App

This is the Hello World program of Flask. It helps you understand how a basic Flask application works.

1️⃣ Create app.py

Inside your project folder, create the following file:


    flask_app/
    │
    ├── app.py

2️⃣ First Flask Code (Write Exactly)


    from flask import Flask
    
    app = Flask(__name__)
    
    @app.route("/")
    def home():
        return "Hello Flask"

3️⃣ Line-by-Line Explanation

from flask import Flask

  • Imports the Flask class from the flask package

app = Flask(__name__)

  • Creates the Flask application instance
  • __name__ helps Flask locate files and resources

@app.route("/")

  • Defines a URL route
  • / represents the home page

def home(): return "Hello Flask"

  • The function handles the request
  • Returns a response to the browser

4️⃣ How Flask Knows What to Show?


    Browser  →  /
    Flask    →  calls home()
    home()   →  returns text
    Browser  →  displays text

5️⃣ Important Rule 🔥

Every Flask route must return something.

  • ✔ String
  • ✔ HTML
  • ✔ JSON

6️⃣ Common Beginner Errors ❌

Error Reason
Page not loading Flask server not running
404 error Route not defined
Nothing showing Function returned nothing

Flask includes a built-in development server that allows you to run and test your application locally while learning and building features.

1️⃣ What is Flask Development Server?

    venv\Scripts\activate

    python app.py

Open in browser:


    http://127.0.0.1:5000/

Modify your app.py file as shown below:

  2. Flask reloads automatically

📘 Topic 6: Routing & URL Rules

Routing decides which Python function runs for a specific URL. It is one of the most important concepts in Flask.

1️⃣ What is Routing?

Routing means mapping a URL to a Python function.

Example:

  • / → home()
  • /about → about()

2️⃣ Basic Route Example


    from flask import Flask
    
    app = Flask(__name__)
    
    @app.route("/")
    def home():
        return "Home Page"
    
    @app.route("/about")
    def about():
        return "About Page"

Browser URLs:

  • http://127.0.0.1:5000/
  • http://127.0.0.1:5000/about

3️⃣ How Routing Works Internally


    Browser requests /about
    Flask finds @app.route("/about")
    Flask calls about()
    Returns response

4️⃣ Dynamic Routes (Very Important)

Dynamic routes allow values to be passed directly through the URL. 


    @app.route("/user/<name>")
    def user(name):
        return f"Hello {name}"

Browser:


    /user/Aman

Output:


    Hello Aman

5️⃣ Dynamic Route with Data Type


    @app.route("/age/<int:age>")
    def show_age(age):
        return f"Your age is {age}"

Supported Types:

Type Meaning
stringDefault text
intInteger
floatDecimal
pathFull path

6️⃣ Multiple URLs for One Function


    @app.route("/")
    @app.route("/home")
    def home():
        return "Home Page"

Both URLs work:

  • /
  • /home

7️⃣ URL Trailing Slash Rule


    @app.route("/contact/")
    def contact():
        return "Contact Page"
  • ✔ /contact/ works
  • ❌ /contact redirects automatically

8️⃣ Best Practices for Routes

  • Use lowercase letters
  • Use hyphens instead of underscores
  • Keep URLs meaningful and readable

Examples:

  • /user-profile
  • /course-details

📘 Topic 7: HTTP Methods (GET & POST)

HTTP methods tell Flask what kind of action the user wants to perform. The two most important methods you will use in Flask are GET and POST.

1️⃣ What are HTTP Methods?

HTTP methods define how data is sent between the browser and the server.

The two most important methods:

  • GET
  • POST

2️⃣ GET Method

🔹 What is GET?

  • Used to fetch data
  • Data is visible in the URL
  • Default method used by the browser

Example URLs:

  • /login
  • /search?q=python

🔹 Flask GET Example


    @app.route("/hello")
    def hello():
        return "Hello from GET request"

✔ Browser sends GET requests automatically ✔ Commonly used for pages and reading data

3️⃣ POST Method

🔹 What is POST?

  • Used to send data to the server
  • Data is hidden inside the request body
  • More secure than GET

Used for:

  • Login
  • Registration
  • Form submissions

4️⃣ Allowing POST in Flask Route

By default, Flask routes allow only GET requests. To allow POST, specify the methods parameter. 


    @app.route("/login", methods=["GET", "POST"])
    def login():
        return "Login Page"

5️⃣ Handling GET vs POST Together


    from flask import Flask, request
    
    app = Flask(__name__)
    
    @app.route("/login", methods=["GET", "POST"])
    def login():
        if request.method == "POST":
            return "Form Submitted"
        return "Login Form"

6️⃣ HTML Form Example (POST)


    <form method="post">
      <input type="text" name="username">
      <input type="submit">
    </form>

7️⃣ Accessing Form Data in Flask


    from flask import request
    
    username = request.form.get("username")

8️⃣ GET vs POST (Quick Comparison)

GET POST
Fetch dataSend data
Data visible in URLData hidden in body
Less secureMore secure
Page loadingForm submission

📘 Topic 8: Returning Responses (Text, HTML, JSON)

Flask can return different types of responses depending on the project requirements. Every Flask route must return a response.

1️⃣ Why Responses Matter?

Whenever a user visits a URL, Flask processes the request and sends something back to the browser.

That returned output is called a response.

2️⃣ Returning Plain Text

Plain text responses are simple and mostly used for testing.


    @app.route("/text")
    def text():
        return "Hello Flask"
  • ✔ Simple
  • ✔ Useful for quick testing

3️⃣ Returning HTML Content

🔹 Option 1: Direct HTML (Not Recommended)


    @app.route("/html")
    def html():
        return "<h1>Hello Flask</h1>"

❌ Hard to manage ❌ Not reusable

🔹 Option 2: HTML Template (Recommended)


    from flask import render_template
    
    @app.route("/")
    def home():
        return render_template("index.html")
  • ✔ Clean code
  • ✔ Professional structure
  • ✔ Reusable templates

4️⃣ Sample index.html


    <!DOCTYPE html>
    <html>
    <head>
      <title>Flask Page</title>
    </head>
    <body>
      <h1>Welcome to Flask</h1>
    </body>
    </html>

5️⃣ Returning JSON (API Response)

Flask APIs usually return responses in JSON format. 


    from flask import jsonify
    
    @app.route("/api")
    def api():
        return jsonify({
            "name": "Aman",
            "course": "Flask"
        })

Browser Output:


    {
      "name": "Aman",
      "course": "Flask"
    }
