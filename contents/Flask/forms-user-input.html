📘 Topic 1: HTML Forms with Flask

Forms are the primary way users send data to a Flask application. They are used for login, registration, contact forms, and searches.

1️⃣ What is an HTML Form?

An HTML form collects user input and sends it to the server for processing.

Common uses:

  • Login
  • Registration
  • Contact forms
  • Search boxes

2️⃣ Basic HTML Form Structure


    <form method="post">
      <input type="text" name="username">
      <input type="submit" value="Submit">
    </form>

Important Attributes:

Attribute Meaning
methodGET or POST
actionURL to send data
nameKey used to access form data

3️⃣ Where Does Form Data Go?


    User fills form
         ↓
    Browser sends request
         ↓
    Flask route receives data
         ↓
    Flask processes input

4️⃣ Create a Simple Form Page

templates/login.html


    <!DOCTYPE html>
    <html>
    <body>
    
    <h2>Login Form</h2>
    
    <form method="post">
      <input type="text" name="username" placeholder="Username">
      <br><br>
      <input type="password" name="password" placeholder="Password">
      <br><br>
      <button type="submit">Login</button>
    </form>
    
    </body>
    </html>

5️⃣ Create Flask Route for Form

app.py


    from flask import Flask, render_template, request
    
    app = Flask(__name__)
    
    @app.route("/login", methods=["GET", "POST"])
    def login():
        if request.method == "POST":
            return "Form Submitted"
        return render_template("login.html")

6️⃣ Important Rule 🔥

If a form uses POST, the Flask route must allow POST.

  • ❌ Missing POST → Error
  • ✔ Use methods=["GET", "POST"]

7️⃣ Form Action Attribute (Optional)


    <form method="post" action="/login">

If the action attribute is omitted, the form submits to the same URL.

8️⃣ Common Input Types

    <input type="email" name="email">
    <input type="password" name="password">
    <input type="submit">

📘 Topic 2: Handling GET vs POST

Understanding the difference between GET and POST is mandatory for proper form handling in Flask.

1️⃣ What is GET?

GET is used to:

  • Fetch data
  • Load pages
  • Pass data through the URL

Example URL:


    /search?q=flask
  • ✔ Data visible in URL
  • ✔ Bookmarkable

2️⃣ What is POST?

POST is used to:

  • Send data securely
  • Submit forms
  • Modify server data
  • ✔ Data hidden in request body
  • ✔ Not bookmarkable

3️⃣ GET vs POST (Simple Comparison)

GET POST
Data in URLData in request body
Less secureMore secure
Default methodExplicit method
Fetch dataSend data

4️⃣ Handling GET & POST in the Same Route

app.py


    from flask import Flask, render_template, request
    
    app = Flask(__name__)
    
    @app.route("/login", methods=["GET", "POST"])
    def login():
        if request.method == "POST":
            return "Login Submitted"
        return render_template("login.html")

5️⃣ Form with GET Method


    <form method="get">
      <input type="text" name="query">
      <button type="submit">Search</button>
    </form>

URL after submit:


    /login?query=python

6️⃣ When to Use GET?

  • Search functionality
  • Filters
  • Pagination

7️⃣ When to Use POST?

  • Login
  • Registration
  • Payments
  • Sensitive data handling

8️⃣ Important Flask Rule 🔥

The Flask route must explicitly allow the HTTP method used by the form.

  • ❌ Using POST without allowing POST → 405 Error
  • ✔ Use methods=["GET", "POST"]
