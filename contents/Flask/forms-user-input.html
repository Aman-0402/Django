Forms & User Input

Handling forms, user input, validations, and POST requests.

📘 Topic 1: HTML Forms with Flask

Forms are the primary way users send data to a Flask application. They are used for login, registration, contact forms, and searches.

1️⃣ What is an HTML Form?

An HTML form collects user input and sends it to the server for processing.

Common uses:

  • Login
  • Registration
  • Contact forms
  • Search boxes

2️⃣ Basic HTML Form Structure


    <form method="post">
      <input type="text" name="username">
      <input type="submit" value="Submit">
    </form>

Important Attributes:

Attribute Meaning
methodGET or POST
actionURL to send data
nameKey used to access form data

3️⃣ Where Does Form Data Go?


    User fills form
         ↓
    Browser sends request
         ↓
    Flask route receives data
         ↓
    Flask processes input

4️⃣ Create a Simple Form Page

templates/login.html


    <!DOCTYPE html>
    <html>
    <body>
    
    <h2>Login Form</h2>
    
    <form method="post">
      <input type="text" name="username" placeholder="Username">
      <br><br>
      <input type="password" name="password" placeholder="Password">
      <br><br>
      <button type="submit">Login</button>
    </form>
    
    </body>
    </html>

5️⃣ Create Flask Route for Form

app.py


    from flask import Flask, render_template, request
    
    app = Flask(__name__)
    
    @app.route("/login", methods=["GET", "POST"])
    def login():
        if request.method == "POST":
            return "Form Submitted"
        return render_template("login.html")

6️⃣ Important Rule 🔥

If a form uses POST, the Flask route must allow POST.

  • ❌ Missing POST → Error
  • ✔ Use methods=["GET", "POST"]

7️⃣ Form Action Attribute (Optional)


    <form method="post" action="/login">

If the action attribute is omitted, the form submits to the same URL.

8️⃣ Common Input Types


    <input type="text" name="name">
    <input type="email" name="email">
    <input type="password" name="password">
    <input type="submit">

📘 Topic 2: Handling GET vs POST

Understanding the difference between GET and POST is mandatory for proper form handling in Flask.

1️⃣ What is GET?

GET is used to:

  • Fetch data
  • Load pages
  • Pass data through the URL

Example URL:


    /search?q=flask
  • ✔ Data visible in URL
  • ✔ Bookmarkable

2️⃣ What is POST?

POST is used to:

  • Send data securely
  • Submit forms
  • Modify server data
  • ✔ Data hidden in request body
  • ✔ Not bookmarkable

3️⃣ GET vs POST (Simple Comparison)

GET POST
Data in URLData in request body
Less secureMore secure
Default methodExplicit method
Fetch dataSend data

4️⃣ Handling GET & POST in the Same Route

app.py


    from flask import Flask, render_template, request
    
    app = Flask(__name__)
    
    @app.route("/login", methods=["GET", "POST"])
    def login():
        if request.method == "POST":
            return "Login Submitted"
        return render_template("login.html")

5️⃣ Form with GET Method


    <form method="get">
      <input type="text" name="query">
      <button type="submit">Search</button>
    </form>

URL after submit:


    /login?query=python

6️⃣ When to Use GET?

  • Search functionality
  • Filters
  • Pagination

7️⃣ When to Use POST?

  • Login
  • Registration
  • Payments
  • Sensitive data handling

8️⃣ Important Flask Rule 🔥

The Flask route must explicitly allow the HTTP method used by the form.

  • ❌ Using POST without allowing POST → 405 Error
  • ✔ Use methods=["GET", "POST"]

📘 Topic 3: Request Object

The request object in Flask holds all the data sent by the client (browser). It is essential for handling forms, query parameters, and HTTP details.

1️⃣ What is the Request Object?

The request object contains:

  • Form data
  • URL parameters
  • HTTP method (GET / POST)
  • Request headers
  • Uploaded files

Import it using:


    from flask import request

2️⃣ Commonly Used Request Properties

Property Used For
request.methodGET or POST
request.argsGET data
request.formPOST data
request.headersRequest headers
request.filesUploaded files

3️⃣ Accessing GET Data (request.args)

URL:


    /search?query=flask

Flask Code:


    @app.route("/search")
    def search():
        query = request.args.get("query")
        return f"You searched for {query}"

4️⃣ Accessing POST Data (request.form)

HTML Form:


    <form method="post">
      <input type="text" name="username">
      <button type="submit">Submit</button>
    </form>

Flask Code:


    @app.route("/submit", methods=["GET", "POST"])
    def submit():
        if request.method == "POST":
            username = request.form.get("username")
            return f"Hello {username}"
        return render_template("form.html")

5️⃣ Difference Between request.args & request.form

request.args request.form
GET dataPOST data
URL query stringRequest body
Less secureMore secure

6️⃣ Accessing Multiple Form Fields


    username = request.form.get("username")
    password = request.form.get("password")

7️⃣ Why .get() is Better Than [ ] 🔥


    request.form.get("email")   # Safe
    request.form["email"]       # Error if missing
  • ✔ Prevents application crashes
  • ✔ Handles missing fields safely
  • ✔ Professional Flask practice

📘 Topic 4: Form Validation Basics

Form validation ensures that users submit correct, complete, and safe data before it is processed by your Flask application.

1️⃣ Why Form Validation is Important?

Without validation ❌

  • Empty input values
  • Invalid or incorrect data
  • Security vulnerabilities

With validation ✅

  • Clean and reliable data
  • Better user experience
  • Safer backend processing

2️⃣ Types of Form Validation

  • Client-side validation (HTML)
  • Server-side validation (Flask – mandatory)

👉 Never rely only on client-side validation.

3️⃣ Client-Side Validation (HTML)


    <form method="post">
      <input type="text" name="username" required>
      <input type="email" name="email" required>
      <button type="submit">Submit</button>
    </form>
  • ✔ Browser prevents empty submission
  • ❌ Can be bypassed easily

4️⃣ Server-Side Validation (Flask)

Basic Empty Check:


    from flask import request, render_template
    
    @app.route("/register", methods=["GET", "POST"])
    def register():
        if request.method == "POST":
            username = request.form.get("username")
            email = request.form.get("email")
    
            if not username or not email:
                return "All fields are required"
    
            return "Registration Successful"
    
        return render_template("register.html")

5️⃣ Validating Length & Format


    if len(username) < 3:
        return "Username too short"
    
    if "@" not in email:
        return "Invalid email"

6️⃣ Displaying Validation Message in Template

Flask:


    return render_template("register.html", error="Invalid input")

HTML:


    {% if error %}
      <p style="color:red;">{{ error }}</p>
    {% endif %}

7️⃣ Common Fields to Validate

  • Empty values
  • Email format
  • Password length
  • Username length

8️⃣ Best Practice 🔥

  • ✔ Always validate on the server
  • ✔ Show user-friendly error messages
  • ✔ Never trust browser-only validation

📘 Topic 5: Flash Messages

Flash messages are short messages shown once after a user action. They are commonly used to display success, error, or informational feedback.

1️⃣ What are Flash Messages?

Flash messages are used to show:

  • ✅ Success messages
  • ❌ Error messages
  • ℹ️ Informational messages

Examples:

  • “Login successful”
  • “Invalid password”
  • “Form submitted”

2️⃣ Why Flash Messages are Needed?

Without flash ❌

  • No feedback to the user

With flash ✅

  • Better user experience
  • More professional applications

3️⃣ Requirement: Secret Key 🔑

Flask requires a secret key to store flash messages securely in sessions.

app.py


    from flask import Flask
    
    app = Flask(__name__)
    app.secret_key = "mysecretkey"

👉 The secret key is required for sessions and flash messages.

4️⃣ Flashing a Message (Backend)


    from flask import flash, request, render_template
    
    @app.route("/login", methods=["GET", "POST"])
    def login():
        if request.method == "POST":
            flash("Login Successful")
        return render_template("login.html")

5️⃣ Display Flash Message in Template

templates/login.html


    {% with messages = get_flashed_messages() %}
      {% if messages %}
        {% for msg in messages %}
          <p style="color:green;">{{ msg }}</p>
        {% endfor %}
      {% endif %}
    {% endwith %}

6️⃣ Flash Messages with Categories (Best Practice)

Backend:


    flash("Login successful", "success")
    flash("Invalid password", "error")

Template:


    {% with messages = get_flashed_messages(with_categories=true) %}
      {% for category, msg in messages %}
        <p class="{{ category }}">{{ msg }}</p>
      {% endfor %}
    {% endwith %}

7️⃣ Example CSS Styling


    .success { color: green; }
    .error { color: red; }

8️⃣ Important Rule 🔥

Flash messages appear only once — after a redirect or page reload.

📘 Topic 6: Redirects & URL Building

Redirects send the user to another page after an action such as form submission, login, logout, or data updates.

1️⃣ What is a Redirect?

A redirect tells the browser: “Go to another URL.”

Common use cases:

  • After form submission
  • Login / Logout
  • After updating data

2️⃣ Why Redirect is Important?

Without redirect ❌

  • Form resubmits on page refresh
  • Duplicate data issues

With redirect ✅

  • Clean user experience
  • Prevents double submission

3️⃣ Redirect in Flask

Flask provides the following helpers:

  • redirect()
  • url_for()

Import them using:


    from flask import redirect, url_for

4️⃣ Basic Redirect Example


    @app.route("/go-home")
    def go_home():
        return redirect(url_for("home"))

👉 Redirects the user to the / route.

5️⃣ Redirect After Form Submit (Best Practice)

Flask Route:


    from flask import request, redirect, url_for, flash
    
    @app.route("/login", methods=["GET", "POST"])
    def login():
        if request.method == "POST":
            flash("Login successful", "success")
            return redirect(url_for("dashboard"))
        return render_template("login.html")

Dashboard Route:


    @app.route("/dashboard")
    def dashboard():
        return "Welcome Dashboard"

6️⃣ Post–Redirect–Get (PRG) Pattern 🔥

What is PRG?


    POST (Form Submit)
         ↓
    REDIRECT
         ↓
    GET (New Page)

Benefits:

  • ✔ Prevents duplicate form submission
  • ✔ Industry-standard pattern
  • ✔ Clean navigation flow

7️⃣ Redirect with Parameters

Route:


    @app.route("/profile/<name>")
    def profile(name):
        return f"Hello {name}"

Redirect:


    return redirect(url_for("profile", name="Aman"))

8️⃣ Redirect vs render_template

redirect render_template
Changes URLKeeps same URL
Safe on reloadReload resubmits form
Used after POSTUsed for GET pages
