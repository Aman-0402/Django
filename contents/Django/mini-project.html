🏆 Student Management System (Mini → Intermediate Level)

📘 Project Description

A web-based system built using Django where student data is fully managed through Django ORM.

What You Build

  • ➕ Add new students
  • 📄 View all students
  • ✏ Update student details
  • ❌ Delete students
  • 🔍 Filter students by course

All data is stored, retrieved, and managed using Django ORM.

🗂️ Database Design

  • Student Table
  • id → AutoField (Primary Key)
  • name → CharField
  • age → IntegerField
  • email → EmailField
  • course → CharField

🧩 Project Modules (Step-by-Step Build)

  • 1️⃣ Student Model
    • Create student table using Django ORM
    • Apply migrations
  • 2️⃣ Add Student
    • Create view to insert data
    • Use ORM .create()
  • 3️⃣ View Students
    • Fetch data using .all()
    • Display records in an HTML table
  • 4️⃣ Update Student
    • Fetch student using .get()
    • Modify data and call .save()
  • 5️⃣ Delete Student
    • Remove record using .delete()
  • 6️⃣ Admin Panel
    • Manage students visually using Django Admin
👉 This mini project perfectly reinforces Django ORM, Models, CRUD operations, Admin Panel usage, and real-world database handling.
