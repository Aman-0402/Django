Course Learning Portal

A Simple Course Learning Portal Built with Django.

🎯 Course Learning Portal — Project Overview

In this project, we build a complete Course Learning Portal using Django that demonstrates real-world concepts like template inheritance, static files, reusable components, and clean URL routing.

📄 Pages We Will Build

Page Purpose
Home Django & Flask course cards
Course Detail Individual course information
About Static content
Contact Static content

🧠 Django Concepts Used

  • Project & App creation
  • URL routing
  • Views
  • Templates
  • Template inheritance
  • Static files (CSS, JS, Images)
  • {% include %} & {% block %}

🌐 STEP 3: URL Configuration

courseportal/urls.py

from django.contrib import admin
  from django.urls import path, include
  
  urlpatterns = [
      path('admin/', admin.site.urls),
      path('', include('course.urls')),
  ]

course/urls.py

from django.urls import path
  from . import views
  
  urlpatterns = [
      path('', views.home, name='home'),
      path('course/<str:name>/', views.course_detail, name='course'),
      path('about/', views.about, name='about'),
      path('contact/', views.contact, name='contact'),
  ]

👁️ STEP 4: Create Views

course/views.py

    
  from django.shortcuts import render
  
  def home(request):
      return render(request, 'home.html')
  
  def course_detail(request, name):
      return render(request, 'course_detail.html', {'course': name})
  
  def about(request):
      return render(request, 'about.html')
  
  def contact(request):
      return render(request, 'contact.html')

🧩 base.html (Template Inheritance Core)

{% load static %}
  <!DOCTYPE html>
  <html>
  <head>
    <title>Course Portal</title>
    <link rel="stylesheet" href="{% static 'css/style.css' %}">
  </head>
  <body>
  
  {% include 'navbar.html' %}
  
  <main>
    {% block content %}{% endblock %}
  </main>
  
  {% include 'footer.html' %}
  
  </body>
  </html>
