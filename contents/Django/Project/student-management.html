🔹 STEP 2.1: What is a Model? (Very Simple)

A Model in Django:

  • Is a Python class
  • Represents a database table
  • Each attribute = column
  • Each object = row
👉 Django ORM uses models to communicate with the database.

✅ STEP 2.2: Write Student Model

Open the file:

students/models.py
from django.db import models
  
  class Student(models.Model):
      name = models.CharField(max_length=100)
      age = models.IntegerField()
      email = models.EmailField(unique=True)
      course = models.CharField(max_length=50)
  
      def __str__(self):
          return self.name

🔍 Explanation of Each Line

class Student(models.Model):

  • Creates a database table named students_student

name = models.CharField(max_length=100)

  • Text column
  • Maximum 100 characters

age = models.IntegerField()

  • Stores numeric age

email = models.EmailField(unique=True)

  • Validates email format
  • unique=True prevents duplicate emails

course = models.CharField(max_length=50)

  • Stores course name (Django, Flask, etc.)

def __str__(self): return self.name

  • Human-readable object name
  • Shown in Django admin & shell

✅ STEP 4.1: Write View to Fetch All Students

from django.http import HttpResponse
  from .models import Student
  
  def list_students(request):
      students = Student.objects.all()   # READ operation
  
      output = ""
      for student in students:
          output += f"""
          Name: {student.name}<br>
          Age: {student.age}<br>
          Email: {student.email}<br>
          Course: {student.course}<br>
          <hr>
          """
  
      return HttpResponse(output)

🔍 Explanation (Line by Line)

  • Student.objects.all()
    ✔ Fetches all rows from the table
    ✔ Returns a QuerySet
  • for student in students:
    ✔ Loops through each database row
  • student.name, student.age
    ✔ Access column values using dot (.) notation
  • HttpResponse(output)
    ✔ Sends plain HTML response to the browser

✅ STEP 4.2: Add URL for READ View

from django.shortcuts import render
  from .models import Student
  
  def student_list(request):
      students = Student.objects.all()   # ORM READ
      return render(
          request,
          'students/student_list.html',
          {'students': students}
      )

🔍 Explanation (Simple)

✅ STEP 6.1: Write DELETE View

from django.shortcuts import redirect
  from .models import Student
  
  def delete_student(request, id):
      student = Student.objects.get(id=id)
      student.delete()
      return redirect('/students/list/')

🔍 Explanation (Line by Line)

  • Student.objects.get(id=id)
    ✔ Fetches a single record using primary key
  • student.delete()
    ✔ Removes the row from the database
  • redirect('/students/list/')
    ✔ Sends user back to the student list page
    📌 Redirect gives better UX than plain text

✅ STEP 7.1: Create UPDATE View

File: students/views.py

from django.shortcuts import render, redirect
  from .models import Student
  
  def update_student(request, id):
      student = Student.objects.get(id=id)
  
      if request.method == "POST":
          student.name = request.POST.get('name')
          student.age = request.POST.get('age')
          student.email = request.POST.get('email')
          student.course = request.POST.get('course')
          student.save()
  
          return redirect('/students/list/')
  
      return render(request, 'students/update_student.html', {
          'student': student
      })

🔍 Explanation (Simple)

  • Student.objects.get(id=id)
    ✔ Fetches the existing student record
  • if request.method == "POST"
    ✔ Checks whether the form is submitted
  • student.save()
    ✔ Executes UPDATE query in database
  • render(...)
    ✔ Displays form with pre-filled data

✅ STEP 7.2: Add UPDATE URL (Dynamic)

🔍 Why CSRF Token?

  • {% csrf_token %} is mandatory for POST requests
  • Protects against CSRF (Cross-Site Request Forgery) attacks
  • Django will reject POST requests without it
