URL Navigation & Hyperlinks

Learn how to create and manage URL navigation and hyperlinks in Django 5 applications.

📘 Create Hyperlink in Django 5 using {% url %} Tag

In Django, URLs should never be hard-coded inside templates. Instead, Django provides the {% url %} template tag to generate links dynamically.

✔ Flexible  ✔ Maintainable  ✔ Error-free  ✔ Production-ready

🔹 Why NOT Use Hard-Coded Links?

❌ Bad Practice

<a href="/course/">Course Page</a>
  • Links break if URL path changes
  • Hard to maintain in large projects
  • Tight coupling between template & URL
  • Not scalable

🔹 Why Use {% url %} Tag?

✅ Best Practice

<a href="{% url 'course' %}">Course Page</a>
  • Auto-updates when URL changes
  • Clean & readable templates
  • Loose coupling
  • Industry standard

🔹 What is {% url %} Template Tag?

  • Generates URLs dynamically
  • Uses name defined in urls.py
  • Works only inside templates
  • Performs URL Reversing
Template → url name → urls.py → actual path

🔹 Basic Syntax

{% url 'url_name' %}
📌 'url_name' must match the name in urls.py

🔹 Step-by-Step Practical Example

🔹 Step 1: Create Project & Apps

django-admin startproject hyperlinkdemo
  cd hyperlinkdemo
  python manage.py startapp course
  python manage.py startapp course1

🔹 Step 2: Create Views

# course/views.py
  from django.shortcuts import render
  
  def course_page(request):
      return render(request, 'course/course.html')
# course1/views.py
  from django.shortcuts import render
  
  def course1_page(request):
      return render(request, 'course1/course1.html')

🔹 Step 3: App URLs (MOST IMPORTANT)

# course/urls.py
  from django.urls import path
  from . import views
  
  urlpatterns = [
      path('', views.course_page, name='course'),
  ]
# course1/urls.py
  from django.urls import path
  from . import views
  
  urlpatterns = [
      path('', views.course1_page, name='course1'),
  ]
⚠️ name is mandatory — without it {% url %} will NOT work.

🔹 Step 4: Project URLs

# hyperlinkdemo/urls.py
  from django.contrib import admin
  from django.urls import path, include
  
  urlpatterns = [
      path('admin/', admin.site.urls),
      path('course/', include('course.urls')),
      path('course1/', include('course1.urls')),
  ]

🔹 Step 5: Create Hyperlinks using {% url %}

<!-- course/course.html -->
  <h1>Course Page</h1>
  
  <a href="{% url 'course1' %}">
    Go to Course1 Page
  </a>
<!-- course1/course1.html -->
  <h1>Course1 Page</h1>
  
  <a href="{% url 'course' %}">
    Back to Course Page
  </a>

🔹 {% url %} with Parameters

# urls.py
  path('details/<int:id>/', views.details, name='details')
<a href="{% url 'details' 5 %}">View Details</a>

Generated URL:

/details/5/

🔹 With Keyword Arguments

<a href="{% url 'details' id=10 %}">Details</a>

🔹 How Django Resolves {% url %}

1. Read URL name from template
  2. Search in urls.py
  3. Match name
  4. Replace with correct path
  5. Render final HTML
📌 This process is called URL Reversing.

❌ Common Mistakes

  • Missing name in urls.py
  • Wrong URL name in template
  • Using {% url %} outside template
  • Typos in URL names
  • Hard-coding URLs

🔹 Hard-Code vs {% url %}

Hard-Code {% url %}
Breaks easily Auto updates
Bad practice Best practice
Not scalable Scalable
Manual changes Automatic
✅ Always use {% url %}
✅ Never hard-code paths
