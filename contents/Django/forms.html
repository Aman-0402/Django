Django Forms & ModelForms

Handle user input safely using Django's built-in Form and ModelForm classes.

📘 What Are Django Forms?

Django Forms are Python classes that handle HTML form rendering, user input validation, and data cleaning — all in one place. Instead of writing raw <input> tags and manually validating data, Django does it for you.

FeatureWithout Django FormsWith Django Forms
HTML renderingWrite manuallyAuto-generated
ValidationWrite manuallyBuilt-in
Error messagesWrite manuallyAuto-generated
CSRF protectionManual{% csrf_token %}

📂 Two Types of Django Forms

  • Form — General-purpose, not tied to a model
  • ModelForm — Auto-generates fields from a Django model (most common)

🟢 Django Form (Manual Fields)

📌 Step 1 — Create forms.py

# students/forms.py

from django import forms

class StudentForm(forms.Form):
    name   = forms.CharField(max_length=100)
    age    = forms.IntegerField(min_value=1, max_value=100)
    email  = forms.EmailField()
    course = forms.CharField(max_length=100)

📌 Step 2 — Use Form in View

# students/views.py

from django.shortcuts import render
from .forms import StudentForm

def add_student(request):
    form = StudentForm()

    if request.method == "POST":
        form = StudentForm(request.POST)
        if form.is_valid():
            name   = form.cleaned_data["name"]
            age    = form.cleaned_data["age"]
            email  = form.cleaned_data["email"]
            course = form.cleaned_data["course"]
            # Save to DB or process here
            return render(request, "students/success.html", {"name": name})

    return render(request, "students/add_student.html", {"form": form})
🔑 GET request → render blank form.
🔑 POST request → validate + process data.
🔑 form.is_valid() triggers all field validators.
🔑 form.cleaned_data gives safe, converted Python values.

📌 Step 3 — Create Template

<!-- students/templates/students/add_student.html -->

<form method="POST">
  {% csrf_token %}
  {{ form.as_p }}
  <button type="submit">Submit</button>
</form>
  • {% csrf_token %} — mandatory, protects against CSRF attacks
  • {{ form.as_p }} — renders each field wrapped in <p> tags
  • {{ form.as_table }} — renders as table rows
  • {{ form.as_ul }} — renders as list items

📌 Step 4 — Connect URL

# students/urls.py

from django.urls import path
from .views import add_student

urlpatterns = [
    path("add/", add_student, name="add_student"),
]

🔵 ModelForm (Recommended for Models)

ModelForm auto-generates form fields directly from your model. No need to repeat field definitions.

📌 Existing Model

# students/models.py

from django.db import models

class Student(models.Model):
    name   = models.CharField(max_length=100)
    age    = models.IntegerField()
    email  = models.EmailField()
    course = models.CharField(max_length=100)

    def __str__(self):
        return self.name

📌 Create ModelForm

# students/forms.py

from django import forms
from .models import Student

class StudentModelForm(forms.ModelForm):
    class Meta:
        model  = Student
        fields = ["name", "age", "email", "course"]
        # OR use fields = "__all__"  to include every field
        # OR use exclude = ["some_field"]  to skip specific fields

📌 View Using ModelForm

# students/views.py

from django.shortcuts import render, redirect
from .forms import StudentModelForm

def add_student(request):
    form = StudentModelForm()

    if request.method == "POST":
        form = StudentModelForm(request.POST)
        if form.is_valid():
            form.save()          # Saves directly to database
            return redirect("student_list")

    return render(request, "students/add_student.html", {"form": form})
✔ form.save() automatically runs INSERT INTO query.
✔ No need to extract cleaned_data manually.
✔ One line replaces the entire CREATE block from CRUD lesson.

🟡 Customizing Fields & Widgets

Widgets control how a field is rendered in HTML. You can override default widgets to use dropdowns, text areas, date pickers, etc. 

# students/forms.py

from django import forms
from .models import Student

COURSE_CHOICES = [
    ("django",  "Django"),
    ("flask",   "Flask"),
    ("fastapi", "FastAPI"),
]

class StudentModelForm(forms.ModelForm):
    class Meta:
        model  = Student
        fields = ["name", "age", "email", "course"]
        widgets = {
            "name":   forms.TextInput(attrs={"placeholder": "Enter full name", "class": "input-field"}),
            "age":    forms.NumberInput(attrs={"min": 1, "max": 100}),
            "email":  forms.EmailInput(attrs={"placeholder": "email@example.com"}),
            "course": forms.Select(choices=COURSE_CHOICES),
        }

🔴 Form Validation

Built-in Validators

  • CharField(max_length=100) — enforces max length
  • EmailField() — validates email format
  • IntegerField(min_value=1) — enforces numeric range
  • required=False — makes field optional

Custom Validation (clean methods)

# students/forms.py

class StudentModelForm(forms.ModelForm):
    class Meta:
        model  = Student
        fields = ["name", "age", "email", "course"]

    # Validate a single field
    def clean_age(self):
        age = self.cleaned_data["age"]
        if age < 16:
            raise forms.ValidationError("Minimum age is 16.")
        return age

    # Validate multiple fields together
    def clean(self):
        cleaned_data = super().clean()
        name  = cleaned_data.get("name")
        email = cleaned_data.get("email")
        if name and email and name.lower() in email.lower():
            raise forms.ValidationError("Email should not contain your name.")
        return cleaned_data

🟣 Edit / Update Form (Pre-filled)

Pass instance= to pre-fill form with existing database record.

# students/views.py

from django.shortcuts import render, redirect, get_object_or_404
from .models import Student
from .forms import StudentModelForm

def edit_student(request, pk):
    student = get_object_or_404(Student, pk=pk)
    form    = StudentModelForm(instance=student)

    if request.method == "POST":
        form = StudentModelForm(request.POST, instance=student)
        if form.is_valid():
            form.save()          # Runs UPDATE query, not INSERT
            return redirect("student_list")

    return render(request, "students/edit_student.html", {"form": form})
# students/urls.py

path("edit/<int:pk>/", edit_student, name="edit_student"),
<!-- Template -->
<a href="{% url 'edit_student' student.pk %}">Edit</a>

⚠️ Displaying Validation Errors in Template

<form method="POST">
  {% csrf_token %}

  {% if form.errors %}
    <div class="error-box">
      Please fix the errors below.
    </div>
  {% endif %}

  {% for field in form %}
    <label>{{ field.label }}</label>
    {{ field }}
    {% if field.errors %}
      <span class="error">{{ field.errors.0 }}</span>
    {% endif %}
  {% endfor %}

  <button type="submit">Save</button>
</form>

🔹 Form vs ModelForm — When to Use

Use CaseUse
Contact form, search form (no model)Form
Create/Edit a model recordModelForm
Custom multi-step formForm
Admin-like CRUD pagesModelForm
