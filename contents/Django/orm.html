Introduction to Django ORM

Understand how Django ORM maps Python classes to database tables and replaces raw SQL.

🔹 What is Django ORM?

Django ORM (Object Relational Mapper) allows you to interact with your database using Python code instead of SQL.

🔁 Simple Mapping

Database Concept Django ORM
Table Python Class (Model)
Row Object (Instance)
Column Class Attribute
SQL Query Python Method
📌 You write Python code — Django automatically generates and executes SQL.

🔹 Example (Simple Understanding)

SQL ❌ (Not Recommended)

SELECT * FROM student WHERE age > 18;

Django ORM ✅

Student.objects.filter(age__gt=18)
  • ✔ Cleaner
  • ✔ Safer
  • ✔ Easier to read

🔹 Why Django ORM is Important?

✅ Key Benefits

  • No raw SQL required
  • Database independent (SQLite, MySQL, PostgreSQL)
  • Prevents SQL Injection
  • Readable & maintainable code
  • Faster development
📌 The same Python ORM code works on any supported database.

🔹 How Django ORM Works (Flow)

Model (Python Class)
        ↓
Django ORM
        ↓
Database (SQL)
📌 You never write SQL manually, but Django executes SQL internally.

🔹 Step-by-Step: Django ORM From Scratch

✅ Step 1: Create Project & App

django-admin startproject ormdemo
cd ormdemo
python manage.py startapp students

🔹 Register App

# ormdemo/settings.py

INSTALLED_APPS = [
    'students',
]
📌 Without registering the app, Django will ignore the models.

✅ Step 2: Create Model (Database Table)

# students/models.py

from django.db import models

class Student(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()
    email = models.EmailField(unique=True)
    course = models.CharField(max_length=50)
    is_active = models.BooleanField(default=True)

    def __str__(self):
        return self.name

🔹 What Django Creates Automatically

Python Database
Student students_student table
name VARCHAR
age INTEGER
email UNIQUE
is_active BOOLEAN
📌 Django also automatically creates:
  • id (Primary Key)
  • Indexes

✅ Step 3: Create Database Tables (Migrations)

python manage.py makemigrations
python manage.py migrate

🔹 What Happens Internally

  • Django generates SQL
  • Applies it to the database
  • Tables are created automatically
📌 No SQL writing required.

✅ Step 4: Register Model in Admin Panel

# students/admin.py

from django.contrib import admin
from .models import Student

admin.site.register(Student)

🔹 Create Admin User

python manage.py createsuperuser
python manage.py runserver

Visit:

http://127.0.0.1:8000/admin/
  • ✔ Add students
  • ✔ Edit students
  • ✔ Delete students
🎯 Django ORM + Admin Panel = powerful, fast backend development.

🔷 Django Model Fields

Django provides many built-in model fields to store different types of data in the database. Below are the most commonly used fields with real-world usage examples.

🔹 1. IntegerField

age = models.IntegerField()

✅ Use When:

  • Age
  • Quantity
  • Count
  • Marks
📌 Stores whole numbers only.

🔹 2. BigIntegerField

phone = models.BigIntegerField()

✅ Use When:

  • Large numbers
  • Phone numbers
  • IDs beyond IntegerField range
📌 Supports very large integers.

🔹 3. AutoField

id = models.AutoField(primary_key=True)

✅ Use When:

  • Auto-increment primary key
📌 Django creates this automatically, so you usually don’t write it.

🔹 4. FloatField

percentage = models.FloatField()

✅ Use When:

  • Decimal values
  • Percentage
  • Ratings
📌 Stores floating-point numbers.

🔹 5. CharField

name = models.CharField(max_length=100)

✅ Use When:

  • Short text
  • Names
  • Titles
  • Course names
📌 max_length is mandatory.

🔹 6. TextField

description = models.TextField()

✅ Use When:

  • Long text
  • Description
  • Comments
  • Articles
📌 Practically no length limit.

🔹 7. BooleanField

is_active = models.BooleanField(default=True)

✅ Use When:

  • True / False values
  • Status flags
  • Availability
📌 Stored as BOOLEAN in the database.

🔹 8. EmailField

email = models.EmailField(unique=True)

✅ Use When:

  • Email addresses
📌 Automatically validates email format.

🔹 9. URLField

website = models.URLField()

✅ Use When:

  • Website links
  • Profile URLs
📌 Validates proper URL format.

🔹 10. BinaryField

data = models.BinaryField()

✅ Use When:

  • Raw binary data
  • Files (rare cases)
📌 Not commonly used in regular Django applications.

🔹 Field Comparison (Quick Revision)

Field Use
IntegerField Whole numbers
BigIntegerField Large numbers
AutoField Auto ID
FloatField Decimal values
CharField Short text
TextField Long text

🎯 Choosing the correct model field ensures data accuracy, validation, and clean database design.
