Template Inheritance with Static Files

Leveraging Django's template inheritance to manage static files efficiently.

📘 Django Template Inheritance & {% block %} Tag

Template Inheritance is a core feature of Django Template Language that lets you reuse a common HTML layout across multiple pages and apps. It follows the DRY Principle (Don’t Repeat Yourself).

🔹 What is Template Inheritance?

  • One base (parent) template
  • Multiple child templates
  • Common layout written once
  • Dynamic content replaced using {% block %}

🔹 Why Do We Use Template Inheritance?

❌ Without Inheritance (Bad Practice)

<header>Menu</header>
  <h1>Django Course</h1>
  <footer>Footer</footer>
<header>Menu</header>
  <h1>HTML Course</h1>
  <footer>Footer</footer>
  • Code repetition
  • Hard to maintain
  • Multiple-file updates for small changes

✅ With Inheritance (Best Practice)

  • Header & footer written once
  • Pages reuse the same layout
  • Only content changes

🔹 Step 1: Register Apps

INSTALLED_APPS = [
      'course',
      'course1',
  ]

🔹 Step 2: Base Template (Parent)

course/templates/course/base.html

<!DOCTYPE html>
  <html>
  <head>
    <title>{% block title %}My Learning Platform{% endblock %}</title>
  </head>
  <body>
  
  <header style="background:#222;color:white;padding:10px">
    <h2>Course Website</h2>
    <a href="/course/">Course</a> |
    <a href="/course1/">Course1</a>
  </header>
  
  <hr>
  
  {% block content %}
  {% endblock %}
  
  <hr>
  
  <footer style="background:#eee;padding:10px">
    <p>© 2025 Learning Platform</p>
  </footer>
  
  </body>
  </html>

🔹 What is {% block %}?

  • Defines a replaceable section
  • Child templates override this content
{% block block_name %}
  {% endblock %}

🔹 Step 3: Child Template – course App

course/templates/course/course.html

{% extends 'course/base.html' %}
  
  {% block title %}
  Django Course
  {% endblock %}
  
  {% block content %}
  <h1>Welcome to Django Course</h1>
  <p>This page uses Template Inheritance.</p>
  {% endblock %}

🔹 What is {% extends %}?

  • Inherits layout from base template
  • Must be the first line in child template
{% extends 'parent_template.html' %}

🔹 Step 4: Child Template – course1 App

course1/templates/course1/course1.html

{% extends 'course/base.html' %}
  
  {% block title %}
  HTML Course
  {% endblock %}
  
  {% block content %}
  <h1>Welcome to HTML Course</h1>
  <p>This page also uses the same base layout.</p>
  {% endblock %}

🔹 Step 5: Views (Business Logic)

course/views.py

from django.shortcuts import render
  
  def course_page(request):
      return render(request, 'course/course.html')

course1/views.py

from django.shortcuts import render
  
  def course1_page(request):
      return render(request, 'course1/course1.html')

🔹 Step 6–7: URLs

course/urls.py

from django.urls import path
  from . import views
  
  urlpatterns = [
    path('', views.course_page),
  ]

course1/urls.py

from django.urls import path
  from . import views
  
  urlpatterns = [
    path('', views.course1_page),
  ]

inheritance/urls.py

from django.contrib import admin
  from django.urls import path, include
  
  urlpatterns = [
    path('admin/', admin.site.urls),
    path('course/', include('course.urls')),
    path('course1/', include('course1.urls')),
  ]

🔹 How Template Inheritance Works (Flow)

Child Template
     ↓ extends
  Base Template
     ↓ blocks replaced
  Final HTML
     ↓
  Browser

⚠️ Important Rules

  • {% extends %} must be the first line
  • Block names must match
  • Base defines blocks
  • Child overrides blocks
  • No Python logic in templates

❌ Common Mistakes

  • Wrong base template path
  • Block name mismatch
  • Forgetting {% extends %}
  • Writing content outside {% block %}

🔷 Template Inheritance with Static Files

🔹 Step 6: Base Template (Parent)

course/templates/course/base.html

{% load static %}
  <!DOCTYPE html>
  <html>
  <head>
    <title>{% block title %}My Website{% endblock %}</title>
    <link rel="stylesheet" href="{% static 'course/css/style.css' %}">
  </head>
  <body>
  
  <header class="header">
    <h2>Learning Platform</h2>
    <a href="/course/">Course</a> |
    <a href="/course1/">Course1</a>
  </header>
  
  <main class="content">
    {% block content %}{% endblock %}
  </main>
  
  <footer class="footer">
    <p>© 2025 Learning Platform</p>
  </footer>
  
  <script src="{% static 'course/js/script.js' %}"></script>
  </body>
  </html>
✔ Load static once in base template
✔ Used automatically by all child templates
✔ Avoids repetition (industry standard)

🔹 Step 7: Child Template – course App

course/templates/course/course.html

{% extends 'course/base.html' %}
  {% load static %}
  
  {% block title %}Django Course{% endblock %}
  
  {% block content %}
  <h1>Django Course Page</h1>
  <img src="{% static 'course/images/django.png' %}" width="200">
  <p>This page uses template inheritance with static files.</p>
  {% endblock %}

🔹 Step 8: Child Template – course1 App

course1/templates/course1/course1.html

{% extends 'course/base.html' %}
  
  {% block title %}HTML Course{% endblock %}
  
  {% block content %}
  <h1>HTML Course Page</h1>
  <p>This page also uses the same base template and CSS.</p>
  {% endblock %}
