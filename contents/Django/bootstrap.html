Using Bootstrap with Django 5

Learn how to integrate Bootstrap into your Django 5 projects for responsive and modern web design.

📘 How to Add Bootstrap in Django 5

Bootstrap is a front-end CSS framework used to build responsive, clean, and professional UI with ready-made components like buttons, cards, navbars, forms, and alerts.

📌 Django handles backend logic only. For UI styling, Bootstrap is commonly used with Django templates.

🔷 Ways to Add Bootstrap

Method Use Case
CDN Learning, quick setup, small projects
Static Files Offline, production, enterprise apps

1️⃣ Method 1: Add Bootstrap using CDN (Beginner Friendly)

🔹 Why Use CDN?

  • No download required
  • Fast setup
  • Auto-updated
  • Best for learning & demos

🔹 Step 1–2: Create Project & App

django-admin startproject bootstrapdemo
  cd bootstrapdemo
  python manage.py startapp course

🔹 Step 3: Register App

INSTALLED_APPS = [
      'course',
  ]

🔹 Step 4: Template with Bootstrap CDN

course/templates/course/index.html

<!DOCTYPE html>
  <html>
  <head>
    <title>Bootstrap in Django</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
          rel="stylesheet">
  </head>
  <body>
  
  <div class="container mt-5">
    <h1 class="text-primary">Welcome to Django Bootstrap</h1>
    <button class="btn btn-success">Click Me</button>
  
    <div class="card mt-4" style="width:18rem">
      <div class="card-body">
        <h5 class="card-title">Django Course</h5>
        <p class="card-text">Bootstrap is working in Django.</p>
        <a href="#" class="btn btn-primary">Learn More</a>
      </div>
    </div>
  </div>
  
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
  </body>
  </html>

🔹 Step 5–7: View & URLs

# course/views.py
  from django.shortcuts import render
  def home(request):
      return render(request, 'course/index.html')
# course/urls.py
  from django.urls import path
  from . import views
  urlpatterns = [ path('', views.home), ]
# bootstrapdemo/urls.py
  from django.contrib import admin
  from django.urls import path, include
  urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('course.urls')),
  ]
python manage.py runserver
🎉 If Bootstrap loads correctly, styles appear instantly.

2️⃣ Method 2: Add Bootstrap using Static Files (Professional)

🔹 Why Use Static Files?

  • Works offline
  • Required for production
  • Full control over version
  • Faster in enterprise setups

🔹 Step 1–2: Download & Place Files

course/
  └── static/
      └── course/
          ├── css/
          │   └── bootstrap.min.css
          └── js/
              └── bootstrap.bundle.min.js

🔹 Step 3: Load Static in Template

{% load static %}
  <!DOCTYPE html>
  <html>
  <head>
    <title>Bootstrap Static</title>
    <link rel="stylesheet"
          href="{% static 'course/css/bootstrap.min.css' %}">
  </head>
  <body>
  
  <div class="container mt-5">
    <h1 class="text-success">Bootstrap via Static Files</h1>
    <button class="btn btn-danger">Delete</button>
  </div>
  
  <script src="{% static 'course/js/bootstrap.bundle.min.js' %}"></script>
  </body>
  </html>
🔑 Always use {% load static %} and {% static %}
❌ Never hardcode static paths.

🔁 Restart Server

CTRL + C
  python manage.py runserver

🔹 CDN vs Static Files

CDN Static Files
Internet required Works offline
Easy setup More control
Best for learning Best for production

❌ Common Mistakes

  • Forgetting {% load static %}
  • Wrong static folder structure
  • Incorrect file paths
  • Missing Bootstrap JS
  • Not restarting server
✅ Django = logic
✅ Bootstrap = UI
✅ Templates = connection layer
