📘 CRUD Operations Using Django ORM

CRUD stands for Create, Read, Update, Delete. These are the four basic operations performed on database data using Django ORM.

🟢 C — CREATE (Insert Data)

📌 Where to Write CREATE Code?

  • Django Shell (for testing & learning)
  • views.py (real application logic)

🟢 CREATE Using Django Shell (Best for Learning)

python manage.py shell
from students.models import Student

Student.objects.create(
    name="Aman",
    age=22,
    email="aman@gmail.com",
    course="Django"
)
  • ✔ One line = INSERT query
  • ✔ Data saved in database

🟢 CREATE Using Views (Real Project Way)

# students/views.py

from django.http import HttpResponse
from .models import Student

def create_student(request):
    Student.objects.create(
        name="Rahul",
        age=21,
        email="rahul@gmail.com",
        course="Flask"
    )
    return HttpResponse("Student Created Successfully")

🔹 Connect URL

# students/urls.py

from django.urls import path
from .views import create_student

urlpatterns = [
    path('create/', create_student),
]
# ormdemo/urls.py

from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('students/', include('students.urls')),
]

Open in Browser:

http://127.0.0.1:8000/students/create/

🔵 R — READ (Fetch Data)

🔵 READ All Students

# students/views.py

from django.http import HttpResponse
from .models import Student

def read_students(request):
    students = Student.objects.all()
    output = ""
    for s in students:
        output += f"{s.name} - {s.course}<br>"
    return HttpResponse(output)
# students/urls.py

path('read/', read_students),

URL:

/students/read/

🔵 READ Single Student

def read_single_student(request):
    student = Student.objects.get(id=1)
    return HttpResponse(student.name)

🔵 READ with Filter

Student.objects.filter(course="Django")
Student.objects.filter(age__gt=18)

🟡 U — UPDATE (Modify Data)

🟡 UPDATE Single Record

# students/views.py

def update_student(request):
    student = Student.objects.get(id=1)
    student.course = "FastAPI"
    student.save()
    return HttpResponse("Student Updated")

🟡 UPDATE Multiple Records

Student.objects.filter(course="Django")
       .update(course="Django 5")
  • ✔ No save() required
  • ✔ Faster bulk update

🔴 D — DELETE (Remove Data)

🔴 DELETE Single Record

# students/views.py

def delete_student(request):
    student = Student.objects.get(id=1)
    student.delete()
    return HttpResponse("Student Deleted")

🔴 DELETE Multiple Records

Student.objects.filter(age__lt=18).delete()

🔹 CRUD Summary (SQL vs Django ORM)

SQL Django ORM
INSERT objects.create()
SELECT objects.all()
WHERE filter()
UPDATE save()
DELETE delete()

🔹 Best Practices (Important)

  • Models → models.py
  • CRUD Logic → views.py
  • URLs → urls.py
  • Testing → Django shell
  • UI → Templates (HTML)
🎯 Mastering CRUD operations means you fully understand Django ORM fundamentals.
