Django Static Files (CSS, JavaScript & Images)

Managing and serving static files in Django projects.

📘 Django Static Files (CSS, JavaScript & Images)

In Django, static files are assets that do not change dynamically and are used for UI & client-side behavior.

  • CSS → Styling & layout
  • JavaScript → Interactivity & logic
  • Images → Logos, icons, banners
📌 Django strictly separates logic (Python) and design (static files) — an industry-standard architecture.

🔹 Step 1: Create Project & App

django-admin startproject useStatic
  cd useStatic
  python manage.py startapp course

Projects hold global config; apps are modular and usually own their static files.

🔹 Project Structure (MOST IMPORTANT)

useStatic/
  ├── manage.py
  ├── useStatic/
  │   ├── settings.py
  │   ├── urls.py
  │
  ├── course/
  │   ├── views.py
  │   ├── urls.py
  │   ├── templates/
  │   │   └── course/
  │   │       └── index.html
  │   └── static/
  │       └── course/
  │           ├── css/
  │           │   └── style.css
  │           ├── js/
  │           │   └── script.js
  │           └── images/
  │               └── django.png
✔ Best Practice: app_name/static/app_name/
✔ Avoids name conflicts • ✔ Auto-discovery • ✔ Scales well

🔹 Step 4–5: Register App & Enable Static

settings.py

INSTALLED_APPS = [
      'course',
  ]
  
  STATIC_URL = '/static/'
❌ If the app isn’t registered, static files will NOT load.

🔹 Step 6–8: View & URLs

course/views.py

from django.shortcuts import render
  
  def home(request):
      return render(request, 'course/index.html')

course/urls.py

from django.urls import path
  from . import views
  
  urlpatterns = [
      path('', views.home),
  ]

useStatic/urls.py

from django.contrib import admin
  from django.urls import path, include
  
  urlpatterns = [
      path('admin/', admin.site.urls),
      path('', include('course.urls')),
  ]
Browser → project urls.py → app urls.py → view → template

🔷 Using Static Files in Templates

index.html

{% load static %}
  <!DOCTYPE html>
  <html>
  <head>
    <title>Django Static Files</title>
    <link rel="stylesheet" href="{% static 'course/css/style.css' %}">
  </head>
  <body>
  
  <h1>Django Static Files Example</h1>
  
  <img src="{% static 'course/images/django.png' %}" width="200">
  
  <script src="{% static 'course/js/script.js' %}"></script>
  </body>
  </html>
🔑 Always use {% load static %}
🔑 Always reference assets via {% static 'path/file' %}
❌ Never hardcode: <img src="/static/django.png">

🔹 Step 10–12: Static Files

CSS — course/static/course/css/style.css

body { background-color: #f4f6f8; }
  h1 { color: darkgreen; }

JavaScript — course/static/course/js/script.js

alert("JavaScript Loaded Successfully!");

Images — course/static/course/images/django.png

⚠️ Very Important Rules

  • Always load static tag
  • Always use {% static %}
  • Never hardcode static paths

🔄 Restart Server (Important)

CTRL + C
  python manage.py runserver
📌 Restart after creating static folders, changing settings, or adding assets.

🔹 Static vs Template

Template Static
HTML structure CSS, JS, Images
Dynamic content Styling & behavior
Uses views No backend logic
✅ Templates = what users see
✅ Static files = how it looks & behaves
✅ Views = who controls it
