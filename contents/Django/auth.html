Django Authentication System

Built-in login, logout, registration, and access control — no third-party library needed.

📘 What Django Auth Provides

Django ships with a complete authentication system out of the box. It handles users, passwords, sessions, and permissions — you just wire it up.

FeatureProvided By
User modeldjango.contrib.auth.models.User
Login / Logoutdjango.contrib.auth.views
Password hashingAutomatic (PBKDF2 + SHA256)
Session managementDjango sessions framework
Access control@login_required, permissions
🔑 django.contrib.auth and django.contrib.sessions are in INSTALLED_APPS by default — nothing to install.

🟢 User Registration

📌 Step 1 — Create Registration Form

# accounts/forms.py

from django import forms
from django.contrib.auth.models import User
from django.contrib.auth.forms import UserCreationForm

class RegisterForm(UserCreationForm):
    email = forms.EmailField(required=True)

    class Meta:
        model  = User
        fields = ["username", "email", "password1", "password2"]
✔ UserCreationForm is Django's built-in form — handles password matching and strength validation automatically.
✔ password1 = enter password, password2 = confirm password.

📌 Step 2 — Registration View

# accounts/views.py

from django.shortcuts import render, redirect
from .forms import RegisterForm

def register(request):
    form = RegisterForm()

    if request.method == "POST":
        form = RegisterForm(request.POST)
        if form.is_valid():
            form.save()               # Creates the User with hashed password
            return redirect("login")

    return render(request, "accounts/register.html", {"form": form})

📌 Step 3 — Template

<!-- accounts/templates/accounts/register.html -->

  <button type="submit">Create Account</button>
</form>

🔵 Login

Django provides a ready-made LoginView — just connect the URL and create a template.

📌 Step 1 — URL

# accounts/urls.py

from django.urls import path
from django.contrib.auth import views as auth_views
from . import views

urlpatterns = [
    path("register/", views.register,            name="register"),
    path("login/",    auth_views.LoginView.as_view(
                          template_name="accounts/login.html"
                      ),                         name="login"),
    path("logout/",   auth_views.LogoutView.as_view(), name="logout"),
]

📌 Step 2 — Login Template

# settings.py

LOGIN_REDIRECT_URL  = "/"        # redirect here after successful login
LOGOUT_REDIRECT_URL = "/login/"  # redirect here after logout
LOGIN_URL           = "/login/"  # redirect here when @login_required blocks access

🔒 Protecting Views with @login_required

Any view decorated with @login_required redirects unauthenticated users to the login page.

FBV — Decorator

# students/views.py

from django.contrib.auth.decorators import login_required

@login_required
def dashboard(request):
    return render(request, "students/dashboard.html")

CBV — Mixin

from django.contrib.auth.mixins import LoginRequiredMixin
from django.views.generic import ListView
from .models import Student

class StudentListView(LoginRequiredMixin, ListView):
    model               = Student
    template_name       = "students/student_list.html"
    context_object_name = "students"
✔ For CBVs, use LoginRequiredMixin — decorators don't work directly on class methods.
✔ Mixin must be the first parent class listed.

👤 Accessing the Logged-In User

In Views

def dashboard(request):
    user = request.user              # the logged-in User object
    print(user.username)
    print(user.email)
    print(user.is_authenticated)     # True if logged in
    return render(request, "dashboard.html", {"user": user})

In Templates

{% if user.is_authenticated %}
  <p>Welcome, {{ user.username }}!</p>
  <a href="{% url 'logout' %}">Logout</a>
{% else %}
  <a href="{% url 'login' %}">Login</a>
  <a href="{% url 'register' %}">Register</a>
{% endif %}

⚙️ Manual Login / Logout (in Views)

For custom auth flows, use Django's authenticate() and login() functions directly.

# accounts/views.py

from django.contrib.auth import authenticate, login, logout
from django.shortcuts import render, redirect

def custom_login(request):
    if request.method == "POST":
        username = request.POST["username"]
        password = request.POST["password"]

        user = authenticate(request, username=username, password=password)

        if user is not None:
            login(request, user)          # creates session
            return redirect("dashboard")
        else:
            return render(request, "accounts/login.html", {"error": "Invalid credentials"})

    return render(request, "accounts/login.html")


def custom_logout(request):
    logout(request)                       # destroys session
    return redirect("login")

🛠️ Creating Users in Code

from django.contrib.auth.models import User

# Regular user
user = User.objects.create_user(
    username="aman",
    email="aman@gmail.com",
    password="securepassword123"   # auto-hashed
)

# Superuser (full admin access)
admin = User.objects.create_superuser(
    username="admin",
    email="admin@gmail.com",
    password="adminpass"
)

🔑 Changing Passwords

from django.contrib.auth.models import User

user = User.objects.get(username="aman")
user.set_password("newpassword456")   # hashes automatically
user.save()
⚠️ After set_password(), the user's session is invalidated. Call update_session_auth_hash(request, user) to keep them logged in. 
from django.contrib.auth import update_session_auth_hash

user.set_password("newpassword456")
user.save()
update_session_auth_hash(request, user)   # keeps current session valid
